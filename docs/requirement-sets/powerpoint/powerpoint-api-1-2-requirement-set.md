# <a name="whats-new-in-powerpoint-javascript-api-12"></a>JavaScript API 1.2 PowerPoint新機能

PowerPointApi 1.2 では、別のプレゼンテーションから現在のプレゼンテーションにスライドを挿入し、スライドを削除するためのサポートが追加されました。

最初の表には API が簡潔にまとめられています。その後の表は詳しい一覧になっています。

| 機能領域 | 説明 | 関連オブジェクト |
|:--- |:--- |:--- |
| [スライドの挿入と削除](/office/dev/add-ins/powerpoint/insert-slides-into-presentation) | 別のプレゼンテーションから現在のプレゼンテーションに既存のスライドを挿入し、スライドを削除できます。 | [Slide.delete](/javascript/api/powerpoint/powerpoint.slide#delete--), [Presentation.insertSlidesFromBase64](/javascript/api/powerpoint/powerpoint.presentation#powerpoint-powerpoint-presentation-insertslidesfrombase64-member(1))|
